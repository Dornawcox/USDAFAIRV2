From tool to question set & visualization guide

This page is converging with the "Talk to the…" method on purpose. Both are structured elicitation instruments: the interview guide structures a conversation with a person; the ranking survey structures a conversation with an application. The evolution path below turns this one-county tool into a maintained, versioned guide any district can fork.

1

Question cards as the unit of the guide

Every card here already holds: official wording, plain-language translation, practice glossary, LWG evidence, and a comment thread. That's the complete anatomy of a question-set entry. The guide is the deck; the deck is data.

Done in this file — one JSON object per question
2

"Talk to the Question" as the comment protocol

The comment prompts follow the interviewer method: one prompt at a time, invite a story not an opinion, capture a headline, gate consent before sharing. A blank box collects complaints; a guided prompt collects evidence the district can actually cite in its Conservation Needs Assessment narrative.

Done — prompts live in each question card
3

Two-round deliberation as the default

Round 1 captures gut priorities in the room; Round 2 captures considered priorities after people have read the full questions and each other's stories. The gap between the two rounds is itself a finding — questions that gain dots after reading are under-explained at meetings; questions that lose dots were riding on their titles.

Done — compare rounds in the tally
4

Version the question set like the interview guide

Per the versioning plan for the interviewer application: each year's question set is a tagged release in a git repo (question JSON + glossary + crosswalk map), with district-proposed changes as pull requests and the STC as the merge authority. The "Additional Feedback" field becomes an issue tracker instead of a black box.

Next — same repo pattern as talk-to-the-interviewer
5

Interview-to-registry pipeline for LWG

The handbook's pipeline — Capture → Consent gates → Structure → Populate — maps exactly: meeting transcript captured, consent handled at sign-in, structured into the quote→concern→question crosswalk, populating both the district report and the statewide heatmap. The March transcript went through this pipeline by hand; the guide documents it so any district can repeat it.

Next — Appendix A of the handbook grows a visualization chapter
6

The visualization guide itself

Codify the four views as reusable patterns with when-to-use guidance: ranked cards (deciding among questions), three-column crosswalk (showing provenance), unit × concern heatmap (situating locally in statewide), two-round tally (deliberation). Each pattern ships with its data shape, so the guide is both a facilitation document and a rendering spec.
